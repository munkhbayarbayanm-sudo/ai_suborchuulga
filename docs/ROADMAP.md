# Roadmap and authorization

Only Phase 01 is authorized. Completion does not authorize the next phase.

| Phase | Scope | State |
|---|---|---|
| 01 | Foundation, Series/Episode, media import, async inspection, metadata, basic UI | implemented; see validation evidence |
| 02 | Embedded subtitles/audio, ASR, OCR, language/source candidates | deferred; explicit approval required |
| 03 | Alignment, source fusion, timing/confidence/speakers | deferred |
| 04 | Mongolian localization, modes, memory, glossary, editorial pipeline | deferred |
| 05 | Professional subtitle editor, sync, AI proposals, autosave, undo | deferred |
| 06 | QC and series consistency, issue-only review | deferred |
| 07 | Non-destructive multitrack video editing | deferred |
| 08 | Subtitle/video export and render jobs | deferred |
| 09 | Mongolian commands producing validated proposed edits | deferred |
| 10 | Batch processing, reliability, benchmarks, deployment/team readiness | deferred |

After approval, Phase 02 starts with inspecting existing MediaAsset/MediaStream
records and specifying extraction outputs, source provenance and provider contracts.
Do not turn stream metadata persistence into subtitle extraction without approval.
